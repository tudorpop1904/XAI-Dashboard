Aplicație Multimodală pentru Operarea unor Consilieri AI Explicați prin XAI

Educație STEM transparentă, accesibilă și privacy-first, cu explicabilitate nativă

Student: Pop Tudor-Ștefan  •  Îndrumător: Portase Raluca Laura

Context & Soluție

Problema

Modelele AI acționează predominant ca un "black-box", reducând încrederea în mediile educaționale STEM. Există o lipsă clară de transparență și multiple bariere de accesibilitate pentru persoanele cu dizabilități.

Soluția Integrată

O platformă web educațională completă cu 3 Consilieri AI care nu doar rezolvă probleme (matematică, programare, scris), ci își și explică detaliat procesul decizional.

Contribuții Cheie
  • Dezvoltarea unor metode originale XAI: Visual PMI și Visual Sobol Indices.
  • Arhitectură Privacy-First (rulare 100% locală, fără apeluri la API-uri externe).
  • Suport avansat de accesibilitate (integrare Text-to-Speech și interfață vizuală adaptabilă).

Arhitectură & Module

🧮 Tutore Matematică

Flux: Imagine rezolvare → VLM (qwen2.5vl) transcrie LaTeX → LLM (llama3.1) verifică și recenzează → Explicare XAI.

✍️ Tutore Scriere

Flux: Caracter desenat pe Canvas → Predicție CNN → Feedback vocal (TTS) corect/incorect → Explicare XAI.

💻 Editor Cod Natural

Flux: Pseudocod în limbaj natural → LLM compilează/formatează cod Python → Execuție → Explicare "eli5" a traducerii.

🔍 Metode XAI Integrate

Sistemul permite aplicarea simultană a metodelor: Occlusion, Grad-CAM, Saliency, Visual PMI, Visual Sobol.

Tehnologii & Impact

Stack Tehnologic Complet Local
  • Backend & ML: Python 3, Streamlit, PyTorch, TorchVision.
  • Inference AI: Ollama + Docker (modele cuantizate Q4_K_M pentru eficiență maximă pe hardware standard).
  • DevOps: Docker, Jenkins CI/CD, GitHub pentru o arhitectură 100% reproductibilă.
Valoare de Cercetare

Platformă unificată ce permite aplicarea a 3-5 metode XAI pentru analiză comparativă directă, măsurând performanța metodologică vs. explicabilitatea generată vs. costul computațional.

Concluzii & Impact

Aplicația demonstrează importanța tranziției la "White-Box AI" și promovează o educație STEM transparentă, sigură și complet incluzivă.
